## Recon (two Explore agents)

Raw findings worth keeping:

- `handoffPrompt` (`run.go:111-114`) was the entire cross-harness handoff: one fixed sentence naming the digest's absolute path, passed as a single positional argv element to every harness; the digest body was never read (only the `client:` frontmatter).
- `continues_from` links were written by hooks but never followed by `run` — `findDigest` picks just the newest incarnation. Pathological real case: the `4f8bca2c...-2` digest is 3 lines for a 3-hour session, so resuming it handed the agent almost nothing.
- Real digests contain doubled `@user-prompt` lines and unescaped nested quotes in Bash lines — the `'...'` quoting is not machine-parseable.
- `run` touched only `.memoria/` (sessions.md, pending/, processed/), never the wiki; the wiki-root resolution pattern was copy-pasted across five files with no shared helper.

## Implementation (TDD, plan agent first)

A Plan agent produced a 7-cycle TDD plan; 7 new tests were written first (red confirmed as a build failure), then implemented to green. Full `scripts/test.sh` (vet + `go test -race`) passes; existing picker/resume/handoff tests untouched and green.

- `buildHandoff` replaces the deleted `handoffPrompt`: a self-contained packet as the agent's single argv prompt — resume framing ("RESUMING … NOT starting a new task"; listed tool calls ALREADY RAN; the current checkout is authoritative), source-harness provenance from `client:`, git checkpoint (`gitCheckpoint`, stub-able package var, omitted outside a repo), digest event history following the `continues_from` chain oldest-first, the wiki `sessions/<sid>.md` page when present, and a footer led by the last `@stop`.
- New helpers: `parseDigest`/`frontKey` (`digestClient` refactored on top), `digestEvents` (per-line cap via `collapse`, consecutive-duplicate dedup), `digestChain` (cycle-safe, depth 5), and `wikiRootFor` in `config.go` (respects the `wiki:` override).
- Budgets: 24k-byte packet, 2k-rune event lines, 6k wiki page; oldest events drop first with a note; the digest paths are always named in the packet.
- Docs updated in the same change: the AGENTS.md run contract and the README run row.

E2E on real data: `./memoria run echo --session 4f8bca2c` — the pathological incarnation-2 digest — produced an 11,462-byte packet carrying incarnation-1's full history via the chain, live git state, and the wiki summary page, which itself tells the agent the earlier work already landed as `0d9d968`.
