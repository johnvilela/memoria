# Session: `cmd/memoria/` flattened into `cmd/` — PR #11

**2026-08-31 16:57–18:28 · project memoria · claude-code · branch `refactor/flatten-cmd`**

Request: remove the redundant nested `cmd/memoria/` folder — the project is already called "memoria" — and move everything up to `cmd/` directly, with the CLI's "root command" registering from `cmd/` rather than a subfolder. Told to work on a new branch off main and to ask refining questions; no clarifying question appears in the digest — the session went straight to an Explore agent instead.

## Recon

An Explore agent (`Explore cmd structure and CLI router`) read `go.mod`, every file under `cmd/`, the router in `main.go`, `help.go`'s command table, every grep hit for `cmd/memoria` across the repo (build scripts, CI workflows, README, AGENTS.md, `.claude/settings.local.json`, and roughly 30 wiki hits, mostly historical session pages), and the `go:embed` directives. Findings — folded into [[concepts/cmd-flattening]] — included: no CLI framework at all (hand-rolled `switch` + stdlib `FlagSet`s); the router and the help-text command list are two registries that don't derive from each other; nothing breaks in Go itself from the move (no package collision, no import cycle, file-relative embeds); but Go names an installed binary after the main package's directory, so `cmd/memoria` → `memoria` while a bare `cmd` → literally `cmd`, permanently breaking the documented `go install .../cmd/memoria@latest` line. The agent suggested the repo root as an alternative that would preserve `go install`, but the user's ask was explicitly to flatten into `cmd/`.

## Implementation

- `git switch -c refactor/flatten-cmd main`
- `git mv cmd/memoria/*.go cmd/` and `git mv cmd/memoria/prompts cmd/prompts` — pure renames, no code edits (everything was already `package main`, embeds are file-relative)
- `sed` path updates across `scripts/build.sh`, `scripts/install.sh`, `.github/workflows/ci.yml`, `.github/workflows/release.yml`, `AGENTS.md`, `README.md`, and a dozen live wiki reference pages (concepts/gotchas/decisions/skills/research) — historical `wiki/sessions/*.md` pages left untouched
- README's `go install github.com/johnvilela/memoria/cmd/memoria@latest` line removed outright, since a main package in a directory named `cmd` would install as a binary literally named `cmd`; manual installs now route through `scripts/install.sh` only
- `cmd/main.go`'s version const bumped 0.12.0 → 0.12.1 (tooling-only patch)

## Verification

`scripts/test.sh` (vet + `-race`): 381 tests green. `scripts/build.sh` then `./memoria version` and, separately, `go run ./cmd version` both printed `memoria 0.12.1`.
