## Recon: where titles actually live

An Explore agent mapped the ground truth before any edit:

- memoria had no title concept — the `sessions.md` NAME slot is the first user prompt collapsed to 80 chars (`indexSession`), and the `transcript_path` hook payload field is never read anywhere in the repo.
- **Claude Code keeps the live title in `~/.claude/sessions/<pid>.json`**: one JSON file per *running* process with `sessionId`, `name` (`nameSource: derived`) and status. Ephemeral — but `stop`/`session-end` hooks fire while the process is alive, so the file is readable exactly when capture needs it. The transcripts under `~/.claude/projects/<slug>/*.jsonl` and `~/.claude/history.jsonl` showed no title key in the Explore agent's greps.
- **Codex is a dead end**: in `~/.codex/state_5.sqlite`, `threads.title` just equals the first prompt and `threads.name` is NULL unless the user manually renamed the thread — no better than memoria's existing fallback, and reading it would need a sqlite driver go.mod doesn't have.

## Implementation — all in `cmd/memoria/hook.go`

The Plan agent's key decision kept the diff small: rewrite the NAME slot of `sessions.md` in place, so `run.go` (picker, `--session` name matching) and the MCP newest-session default need zero changes — they already read NAME.

- `claudeTitle(sid)` — scans `~/.claude/sessions/*.json` for the matching `sessionId`, returns `name`; every error path returns `""` (best-effort, hooks never fail the agent).
- `captureTitle(proj, sid)` — `collapse(title, 80)`, writes `title:` into the pending digest incarnation's frontmatter, skips when unchanged, then calls `renameSession`. Codex skipped with a `ponytail:` comment naming the ceiling.
- `renameSession(proj, sid, title)` — in-place NAME rewrite by exact sid match, safe with " - " inside names.
- `setEndedAt` generalized to `setFront(path, key, val)` — one frontmatter writer, two users.
- Wired into `captureHook` on `stop` + `session-end`, `--client claude-code` only.

6 new tests (title lookup, stop capture, idempotence, codex exclusion, rename preserving neighbor lines, no-digest no-error); full suite, gofmt and vet green. The dev binary at `~/.local/bin/memoria` was rebuilt, and a manual `hook stop` against this very session flipped its `sessions.md` line from the first-prompt text to `capture-agent-session-titles`.
