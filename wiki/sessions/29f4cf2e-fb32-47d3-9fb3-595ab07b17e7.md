## The gaps

Three installer friction points blocked easy setup:

1. **Module path mismatch**: `go.mod` declared `github.com/jv77/memoria`, but the GitHub repo is at `github.com/johnvilela/memoria`. This made `go install ...@latest` impossible — the README's documented install path was broken.
2. **No installer script**: users had to clone, run `go build`, and manually handle shell PATH setup.
3. **No PATH repair automation**: after install, macOS/zsh users found `~/.local/bin` not on PATH by default, hitting the screenshot bug from [[sessions/44c49197-2dea-4615-8ec2-27849c744218]]. The `wiki/to-do/install-script-path.md` noted this but had no solution.

## The fixes

**Module path corrected**: `go.mod` and `AGENTS.md` renamed `jv77` → `johnvilela`. This unblocks `go install ...@latest`.

**`scripts/install.sh`** (new): portable one-line installer that:
- Detects OS (`uname`); rejects non-Linux/macOS
- Builds local checkout or `go install`s from GitHub
- Detects installed agents (`claude`, `codex` on PATH) and passes `--client` to init
- Runs `memoria init </dev/tty` so interactive picker works under `curl | sh` (headless prints next steps)

**`memoria init` PATH repair** (`ensurePathEnv` in init.go): new function that:
- Checks if binary dir is on PATH; if not, appends to the right shell rc:
  - `~/.zshrc` (zsh)
  - `~/.bashrc` (bash)
  - `~/.config/fish/config.fish` with `fish_add_path` (fish)
  - `~/.profile` (fallback)
- Portable: paths written as `$HOME/...`
- Idempotent: skips if line already present
- Best-effort: never fails init, prints "added … restart your shell"

**Tests**: `TestEnsurePathEnvAppendsShellRC` (append, idempotence, skip-when-on-PATH) + `TestShellRC` table covering all shells; existing tests safe (HOME mocked).

**Wiki cleanup**: moved resolved `wiki/to-do/install-script-path.md` → `wiki/trash/` and tagged `deleted`.

## Outcome

The macOS PATH screenshot bug is now permanently fixed: on next `memoria init`, the binary is automatically added to PATH.

**README** install section now leads with:
```sh
curl -sS https://raw.githubusercontent.com/johnvilela/memoria/main/scripts/install.sh | sh
```

No OS/shell flag added to init itself — the binary already self-adapts (`runtime.GOOS`: systemd vs launchd); the script only handles what the CLI can't see.
