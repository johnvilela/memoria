## Recon (Explore agent)

- `runStatus` (status.go:122-147) was four `fmt.Fprintf` branches with no styling at all. `procStatus` (status.go:18-24) has only `State`, `PID`, `StartedAt`, `FinishedAt`, and a free-form `Detail` string — "pages applied"/"sessions" counts are baked into `Detail` by the producers (process.go, lint.go, seed.go, digest.go, mcp.go), not structured fields.
- `go.mod` already carried `bubbles v1.0.0`, `bubbletea v1.3.10`, `lipgloss v1.1.0`, and `golang.org/x/term v0.45.0` as **direct** dependencies — no new dependency needed. The CLI itself is a hand-rolled `switch` in main.go (no cobra/urfave/pflag).
- `tui.go` already has shared lipgloss style vars (`tuiTitle`, `tuiCursor`, `tuiFaint`) and an `isTTY` var (checks stdin) used as a test seam elsewhere in the codebase.
- `status_test.go`'s `TestRunStatusOutput` only asserts via `strings.Contains` on substrings, so restyling was safe as long as ANSI codes didn't split those substrings — lipgloss wraps whole rendered strings, so this held.

## Implementation

A plan was written, then `feat/status-table` was branched off `main`. `status.go` was edited twice, `main.go` got the version bump, and `status_test.go` gained a new header-row assertion. Verified with `go build`, `go test`, a live `memoria status` run, and a piped run through `cat` to confirm non-TTY output degrades to plain text.

Committed as `feat(status): render status as a styled table`, pushed, and opened as **PR #5** — deliberately left unapproved per the original instruction.

## The result

A borderless lipgloss table replacing the four prose lines:

```
PROJECT STATUS DETAIL FINISHED
bsj ● done applied 4 pages from 1 sessions Aug 21 12:02 (5d ago)
eparts ● done applied 5 pages from 1 sessions Aug 26 20:31 (2h ago)
```

State renders as a colored glyph using base ANSI colors so it follows the terminal's theme (green ● done, red ✗ error, yellow ◌ running); `Detail` is capped at 80 chars via the existing `collapse` helper; timestamps show both absolute and relative age. Piped/non-TTY output degrades to plain text automatically. Version bumped to **0.10.0** for the CI gate ([[decisions/0012-ci-cd-release-pipeline]]'s `version-check`).

Bubbles was deliberately skipped — "a static render needs only `lipgloss/table`; bubbles only earns its keep if you later want the interactive live-refresh view."
